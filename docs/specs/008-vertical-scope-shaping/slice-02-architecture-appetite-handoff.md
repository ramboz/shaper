## Slice 008-02 — architecture-appetite-handoff

**Goal:** The release plan's handoff carries a bounded **architecture-appetite**
ceiling — a leanness stance jig reads before drafting specs — and `shape-release`
enforces the guardrail that keeps that field appetite-shaped (appetite / no-gos /
risk-pointer only, never ADRs, design, or module boundaries).

**DoR:**
- ✅ 008-01 done (vertical scopes exist to attach an appetite to).
- ✅ ADR-0005 fixes the boundary: shaper expresses architecture *appetite*; jig
  makes architecture *decisions*.

**Acceptance Criteria:**

1. **The handoff carries an architecture-appetite field with the accepted
   three-element content model.** `## JIG Handoff` in `templates/release-plan.md`
   gains an "Architecture appetite" entry with exactly the three ceiling-shaped
   elements ADR-0005 fixes (Recommended Decision), and **no "proposed shape"
   slot**: (i) **Investment posture** — a strict *upper bound* on architectural
   investment ("at most" / "permitted up to," never "at least"; the spectrum runs
   *throwaway is enough → durability permitted, not required*); (ii)
   **Over-investment no-gos** — specific over-builds to refuse (a refusal, never a
   selection); (iii) **Spike pointer** — architectural risk worth retiring early.
   The field must not contain a "the leanest architecture is X" line — completing
   that sentence names a mechanism, which is jig's decision. Existing handoff
   fields (candidate specs / new work / patch-ready instructions / non-mutating
   notes) are preserved.
2. **`shape-release` elicits it and states the guardrail.** The skill's
   "Inputs to gather" includes architecture appetite (the three elements above),
   and its **Boundaries** section states the load-bearing rule from ADR-0005:
   shaper records architecture *appetite / over-investment no-gos / spike pointer
   only* — the investment posture is an **upper bound only** (never a floor or a
   minimum), and the skill must **not** write ADRs, name module boundaries, a
   mechanism, or any positive design; jig owns those. This is enforced as a
   boundary the skill will not cross, not merely a style note.
3. **The field degrades safely.** When the maintainer gives no architecture
   appetite, the field is written as `TBD` (advisory, non-blocking) — never
   fabricated, and never escalated into a design by the skill.
4. **Cross-reference to the jig-side complement is recorded.** The plan template
   (or skill docs) notes that architecture appetite is the prospective half; the
   retrospective half is jig's leanness/YAGNI review lens — so a reader knows
   this ceiling is advisory-at-shaping and gets enforced downstream at jig
   review, not by shaper.

### Reconciliation sweep

- **Review verdicts:** compliance `pass`; craft `pass` **after a blocker fix**.
  Evidence: `reviews/slice-02-compliance.md`, `reviews/slice-02-craft.md`.
- **Craft blocker fixed (data loss):** nesting `### Architecture appetite` under
  `## JIG Handoff` meant a refine passing `--jig-handoff` *and* an arch flag
  appended the handoff bullet *after* the arch subsection, where
  `_set_arch_appetite`'s rewrite then silently deleted it. Fixed by making
  `_append_section_bullets` insert new bullets **before** the first nested
  `### ` subsection (end-of-section fallback when none). Regression test
  `test_refine_jig_handoff_and_arch_flag_together_preserves_both` was verified
  **red** on the pre-fix code (bullet dropped) and **green** after. A focused
  craft re-review confirmed the blocker is resolved with no new blocker and no
  regression to the other sections that share `_append_section_bullets`.
- **Cross-slice benefit:** the same fix also resolves slice 008-01's logged
  cosmetic nit-1 — a `--solution` bullet supplied with vertical scopes now
  precedes the `### Vertical Scopes` subsection instead of trailing it.
- **Logged nits (not blockers):**
  - The `"; ".join(no_gos)` / `.split("; ")` round-trip renders identically
    (no file-level loss) but can fragment a single no-go that itself contains a
    literal `"; "`, defeating dedup for that compound value on re-supply.
    Left as-is (uncommon prose shape); revisit with a non-prose separator if it
    ever bites.
  - The four `_arch_appetite_*` helpers structurally mirror the
    `_vertical_scopes_*` helpers. Acceptable duplication given divergent payloads
    (three labelled fields vs. an ordered list); a shared "nested-subsection"
    helper could unify them later if a third such subsection appears.
- **Shared-helper side-effect (benign, logged):** because
  `_append_section_bullets` is shared, the insert-before-nested-`###` fix also
  changes where a fall-through `--cutline` bullet lands (now before `### Include`
  instead of after `### Risk-First`). Only reached after the four `## Cutline`
  TBD table rows are consumed, and appending a loose bullet to a table-structured
  section is already an edge; behaviourally benign. Noted for transparency.
